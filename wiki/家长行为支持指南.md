# 家长行为支持指南

> 最近核对：2026-09-29。本指南提炼自星星雨文章《为了孩子，这27种方法要烂熟于心》，并参考 2020 年 NCAEP 更新。它用于帮助家长理解和配合干预，不替代对孩子的个别评估或专业方案。

## 来源与使用边界

- 原文：[为了孩子，这27种方法要烂熟于心](http://www.guduzh.org.cn/?p=13617)
- 原文网页发布于 2022-06-23，正文注明内容最早发表于 2017-02-20，主要依据美国国家自闭症中心 2015 年 National Standards Project。
- 更新参考：[Evidence-Based Practices for Children, Youth, and Young Adults with Autism: Third Generation Review](https://pmc.ncbi.nlm.nih.gov/articles/PMC8510990/)。该综述将文献范围更新至 2017 年，识别出 28 类聚焦式循证实践，并强调根据孩子的目标和特点选择方法。
- 文章中的 27 个名称不是 27 套必须全部完成的课程，也不代表每种方法对每个孩子、每个目标都同样适合。
- 家庭支持应以沟通、自主、参与、生活适应和安全为目标，不以强迫眼神接触、压制无害的自我调节行为或让孩子表现得“看不出孤独症”为目标。

## 家庭行为支持闭环

### 第一步：只选一个可观察目标

目标应描述孩子要做的动作、发生场景和支持程度。

不清楚的目标：

- “听话一点”
- “社交好一点”
- “不要闹”

可记录的目标：

- 听到“收玩具”后，在一次图片提示下，把 3 件玩具放入收纳箱。
- 想要同伴手里的物品时，用说话、手势或图片提出请求，等待对方交付。
- 超市游戏中递出第一件商品后，主动或看提示卡询问“还要什么”。

一次只练一个小目标。孩子已经稳定完成后，再增加步骤、对象或场景。

### 第二步：记录行为前后发生了什么

连续记录几次同类事件：

| 项目 | 记录内容 |
| --- | --- |
| 场景 | 时间、地点、参与者、正在进行的活动 |
| 行为之前 | 成人说了什么；活动是否突然变化；任务是否过难；孩子是否等待、疲劳、饥饿或身体不适 |
| 可观察行为 | 孩子具体说了什么、做了什么；不使用“故意”“懒”“不配合”等原因判断 |
| 行为之后 | 成人、同伴怎样回应；孩子得到、避免或延迟了什么 |
| 可能需要 | 物品、帮助、休息、结束、关注、可预测性、感官调节或身体舒适 |

这一步对应文章中的功能性行为评估。家庭记录只能形成初步假设；涉及自伤、攻击、逃跑、严重破坏或持续升级的行为，应由专业人员进行正式评估。

### 第三步：先调整环境，降低困难

对应方法：先行干预、视觉支持、社会故事、脚本法。

- 提前告诉孩子接下来做什么，可用“先……再……”图片或两步口头说明。
- 转场前给出可理解的预告，例如视觉计时器、倒数或固定提示语。
- 把任务缩短，减少一次出现的材料和语言。
- 提供两项都能接受的选择，而不是开放式追问。
- 利用孩子的兴趣安排材料、角色和强化活动。
- 清楚展示物品位置、完成范围和结束标志。
- 如果孩子对噪声、拥挤、等待或身体不适敏感，先处理环境和生理需要。

环境调整不是“迁就所有要求”，而是让目标处于孩子能够学习的难度。

### 第四步：教一个能替代原行为的沟通方式

对应方法：功能性沟通训练、图片交换沟通、辅助与替代沟通。

优先教授高频、能立即解决问题的表达：

- “帮我。”
- “休息。”
- “不要／停一下。”
- “还要。”
- “结束了。”
- “可以给我……吗？”
- “请让一让。”

表达形式可以是口语、手势、图片或沟通设备。关键是这种表达应比原有困难行为更容易使用，并能获得相同功能的合理回应。

### 第五步：示范、少量提示，然后等待

对应方法：示范、视频示范、提示、时间延迟、回合教学。

推荐顺序：

1. 先让孩子看到成人或同伴示范。
2. 发出简短、明确的指令。
3. 等待 3—5 秒，让孩子有独立回应机会。
4. 没有回应时，给予刚好足够的提示，例如指图片、做手势、说第一个字。
5. 仍有困难时，再提供更直接的示范或帮助。
6. 孩子开始掌握后，逐渐延长等待时间、减弱提示。

避免同一句话快速重复多次，也不要在孩子已经开始行动时继续追加指令。

### 第六步：立即强化要增加的行为

对应方法：强化、区别强化、关键反应训练。

- 强化应紧跟目标行为，让孩子容易理解两者的关系。
- 优先使用自然结果：提出“还要”后得到下一轮游戏；说“帮我”后获得帮助；完成收玩具后进入下一项喜欢的活动。
- 对尝试也给予回应，不要求第一次就表达完整。
- 强化物因人而异，成人觉得是奖励的东西不一定对孩子有强化作用。
- 随着技能稳定，将高频外在奖励逐步转为活动本身、成功感和自然社交回应。

区别强化的家庭原则是：让合适的替代行为更容易成功、更快得到回应，而不是只关注如何忽略困难行为。

### 第七步：把复杂活动拆成小步骤

对应方法：任务分析、脚本法、视觉支持、视频示范。

例如“当超市老板”可拆为：

1. 看向或转向顾客。
2. 听顾客说需要什么。
3. 找到商品。
4. 把商品递给顾客。
5. 询问“还要什么”。
6. 说出价格。
7. 收钱并结束交易。

先确定孩子已经会的步骤，只教当前最需要的一两个步骤。不要每次从头到尾同时纠正。

### 第八步：在真实生活中短时、重复练习

对应方法：自然式教学、家长实施干预、同伴介导和结构化游戏。

- 把练习放进吃饭、穿衣、收拾、购物游戏、户外活动和同伴玩耍中。
- 每次练习保持短而成功，可在一天中自然出现多次。
- 使用孩子当下真正想要的物品或活动，创造沟通机会，但不要故意长时间扣住必需品。
- 在成人、同伴、房间或材料变化时继续练习，观察技能是否泛化。

### 第九步：记录独立程度，而不只记录“会不会”

每次只需标记：

- `独立`：没有针对性提示。
- `轻提示`：图片、手势或等待后完成。
- `直接提示`：成人说出答案、完整示范或动作帮助。
- `未完成`：本次没有完成，记录可能影响因素。

连续一至两周没有改善时，应检查目标是否过难、替代沟通是否真的有效、强化是否及时，以及行为功能假设是否错误，而不是单纯增加练习次数。

## 方法分级

### 家长可优先学习和日常使用

- 先行干预：调整材料、任务、顺序和转场提示。
- 视觉支持：图片日程、先后板、视觉规则、计时器。
- 自然式教学：跟随兴趣，在日常活动中创造学习机会。
- 家长实施干预：在专业人员培训和反馈后，将策略用于家庭生活。
- 示范与视频示范：展示目标动作或互动方式。
- 提示与时间延迟：给足等待时间，并逐步撤除帮助。
- 强化：及时回应目标行为和合理沟通。
- 任务分析：把复杂技能拆成小步骤。
- 脚本与社会故事：预告活动过程和可用表达，并在掌握后逐渐撤除。
- 运动：用于体能、参与和调节，不把运动当作惩罚。

### 建议与专业人员共同制定

- 功能性沟通训练、PECS 或其他辅助沟通系统。
- 回合教学、关键反应训练、同伴介导、社交技能训练和结构化游戏组。
- 对频繁问题行为进行区别强化或正式功能性行为评估。
- 使用技术或沟通设备支持表达、学习和生活技能。

### 不建议家长自行使用

- 消退法：可能出现行为短期升级；如果判断错了行为功能，也可能让孩子失去合理沟通途径。
- 反应中断／转移：不应为了消除无害的重复动作或自我调节而频繁打断孩子。
- 针对自伤、攻击、逃跑、进食、睡眠、如厕或明显身体不适的行为方案。
- 长时间忽略、强迫身体配合、扣留基本需要、惩罚性运动或让同伴反复拒绝孩子以制造训练机会。

这些情况需要明确的功能评估、安全计划、替代技能和专业监督。

## 结合近期记录的家庭示例

### 示例一：超市老板主动追问

目标：递出第一件商品后，询问“还要什么”。

1. 准备一张老板流程卡：“你要什么 → 给商品 → 还要什么 → 多少钱”。
2. 家长先完整示范一轮。
3. 游戏时递出商品后等待 3 秒。
4. 没有回应时先指向流程卡；仍未回应，再提示“还要……”。
5. 可乐说出或接近目标表达后，顾客立即继续购买，让游戏自然延续。
6. 稳定后逐渐遮住文字、减少指卡，最后撤除流程卡。

使用的方法：视觉支持、脚本、示范、时间延迟、提示、自然强化。

### 示例二：向同伴提出要求并等待

目标：想要同伴手中物品时，用请求表达并等待交付。

1. 先练习固定表达：“可以给我……吗？”也可使用手势或图片。
2. 成人示范一次后，让可乐自己尝试。
3. 请求后让同伴尽快交付，强化“说／表示后等待”的完整过程。
4. 如果直接伸手拿，成人平静挡住动作，立即提示替代表达；不批评、不长篇说理。
5. 后续逐步减少语言提示，只保留等待或手势提示。

使用的方法：功能性沟通训练、示范、提示、时间延迟、区别强化。

### 示例三：当天第一次集体指令

目标：第一次听到搬椅子、站线等集体指令时开始行动。

1. 活动前用两三张图片预告：“邀请同伴 → 搬椅子 → 玩游戏”。
2. 发出集体指令后等待 3—5 秒。
3. 没有行动时，先指流程图片或已经行动的同伴；避免连续重复完整指令。
4. 开始行动后立即肯定具体动作，例如“你听到搬椅子就开始搬了”。
5. 记录第一次指令是独立、轻提示还是直接提示完成，观察是否逐渐减少支持。

使用的方法：先行干预、视觉支持、同伴示范、时间延迟、强化。

### 示例四：商品板让顾客也能看到

目标：有顾客时将商品板平放。

1. 用两张图片展示：“有顾客—平放”“没有顾客—可以竖放”。
2. 顾客到来前提示一次，让可乐选择并摆放。
3. 如果仍竖放，由顾客用自然语言表达“我看不到”，成人指向图片规则。
4. 平放后立即开始购买，不反复纠正摆放角度。

使用的方法：视觉支持、先行干预、自然结果和强化。

## 家庭记录模板

```text
日期／场景：
本次小目标：
行为之前发生了什么：
孩子具体做了什么：
行为之后发生了什么：
可能的需要或功能（只是初步假设）：
准备教的替代沟通／技能：
环境支持：
提示顺序：
自然强化：
结果：独立／轻提示／直接提示／未完成
下次只调整一项：
```
