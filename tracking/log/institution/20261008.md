# 机构干预日志：2026-10-08

根据老师本次聊天转写整理。表格中的“—”表示未提及，不代表无需支持。

| 活动/情境 | 观察到的表现 | 提示/支持 |
| --- | --- | --- |
| 节后返课与互动音量 | 老师接可乐时，可乐回应的声音较小；进入教室后，与老师说话逐渐恢复到正常音量。前半节课回应或邀请同伴时声音仍较小；后半节课能够自然地用正常音量与同伴互动，不再需要重复提醒。 | 老师肯定其表达内容，并提醒下次声音可以再大一点；可乐曾主动询问自己的音量是否合适，老师给予肯定。 |
| 集体指令：站红线 | 第一次听到站红线的集体指令后，能够和其他小朋友一起较快站到红线上；后续面对措辞有所变化、但都包含站红线要求的集体指令，也能在听到指令后完成。 | 老师以“请小朋友们”“大家”等不同自然说法发出集体指令；未提及针对可乐的单独提醒。 |
| 集体指令：搬椅子 | 面对把椅子搬到指定位置、游戏结束后收椅子等不同集体指令，能够和其他小朋友一起完成。老师观察到可乐是在听到指令后开始行动。 | 老师以不同说法向全体小朋友发出搬椅子或收椅子的指令；未提及针对可乐的单独提醒。 |
| 回答个人信息：父母姓名 | 面对小朋友询问妈妈或爸爸叫什么，前半节课能够回答，声音较小但老师可以听清；后半节课再次回答时，音量自然增大。 | 老师安排小朋友向可乐提问。 |
| 邀请同伴参加活动 | 第一次邀请同伴坐地铁时，走到同伴面前但没有开口，经示范后说出邀请。后续玩其他游戏或玩具时，在老师说明要玩的活动并要求邀请同伴后，能够走到同伴旁边说出邀请。 | 第一次老师说明活动缺少参与者，并示范“我们一起去坐地铁吧”等邀请语句；后续仍由老师说明活动并提出邀请要求，但不再每次示范具体话语。 |
| 向同伴提出要求 | 前半节课需要同伴手中的磁力片等物品时，较多出现站在同伴旁边看着但不说话的情况；也出现过表达后未等待同伴交付，直接伸手拿物品的情况。后半节课能够向同伴说“我想要那个绿色磁力片”“我想要数字火车”等，但有时说完后仍会立即伸手拿。 | 老师带可乐寻找所需物品，并教他说出具体请求；继续提醒其表达后等待同伴交付。 |
| 假想游戏：服装店老板 | 扮演服装店老板时，能够询问顾客想要什么；顾客提出购买裙子后，会取下裙子交给顾客。等待片刻后，还主动继续询问“你还要什么”。 | 老师组织超市假想游戏；本次转写未提及老板对话中的额外语言提示。 |
| 社会性游戏：抢椅子 | 前两轮在参与人数与椅子数量相同的情况下练习规则；减少一把椅子后，能够持续关注椅子，在音乐停止时立即尝试抢椅子坐下。一次没有抢到椅子时，没有生气或难过，站在旁边看着，表现得有些尴尬。 | 老师先通过前两轮帮助小朋友熟悉规则；未抢到时，引导可乐用“我下次一定要抢到椅子”“我下次再加油”等方式表达，可乐跟随老师说出。 |
| 社会性游戏：地雷爆炸新规则 | 新规则中，老师扮演追赶小朋友的“坏人”。老师接近时，可乐能够说“地雷”；老师离开后，尚不能自行说“爆炸”并恢复走动，本次多次游戏均需要提醒。 | 老师在离开后提示“现在坏人走了，可以说爆炸”，并继续带领可乐练习新规则。 |
| 问题解决：高处物品 | 物品太高时，先跳起来尝试拿取；拿不到后，在老师询问下请求老师帮忙。老师继续询问如果自己也拿不到怎么办时，可乐提出搬椅子，让老师踩着椅子取物品。 | 老师通过追问，引导可乐继续想不同办法。 |
| 问题解决：别人挡住 | 老师、其他老师或小朋友挡住时，能够说“你挡住我啦，你让一让”。 | 通过不同人员参与角色扮演，练习用语言表达让路要求。 |
| 问题解决：物品掉进柜子缝里 | 小火车掉进柜子缝后，先尝试搬动柜子；搬不动时说“太重了，我力气太小了，搬不动”。老师让其再想办法后，可乐请求老师帮忙搬。 | 老师设置真实情境，并在原有办法无法完成时提示继续想其他办法。 |

老师表示，后续会继续练习邀请和请求同伴、地雷爆炸新规则及问题解决，并巩固假想游戏角色。这些是后续教学计划，并非今天已达到的表现。
