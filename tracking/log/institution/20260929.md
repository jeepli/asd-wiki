# 机构干预日志：2026-09-29

根据老师本次语音转写整理。表格中的“—”表示未提及，不代表无需支持。

| 活动/情境 | 观察到的表现 | 提示/支持 |
| --- | --- | --- |
| 假想游戏：超市老板的对话 | 扮演老板时，顾客购买一件商品后，尚未主动追问“还要什么”。老师扮演顾客并带着可乐练习老板角色。顾客提出需求时，可乐会取下商品，看着顾客并把商品递给对方。 | 老师提醒可乐询问顾客是否还需要其他商品，并通过先与老师练习来示范老板的交流过程。 |
| 假想游戏：商品板的摆放 | 扮演老板时，可乐习惯把磁力商品板竖起来，板上内容朝向自己、顾客看不到。老师要求平放时，他起初仍用力扶着板保持竖立，但没有出现情绪；老师说明顾客看不到，小朋友也询问“这里有什么，我看看”后，他跟着老师把板平放到桌面。 | 老师说明有顾客时需要平放商品板、没有顾客时可以竖放；同伴也用提问表达了查看商品的需要。 |
| 社会游戏：抢椅子 | 在约 3 分钟的游戏时段中参与活动。刚开始不太会按音乐开始和停止来行动；跟着玩了两三轮后，能够理解音乐停止时要尽快坐到椅子上，并参与争抢椅子。 | 老师带领可乐重复玩两三轮，并在规则执行上给予引导。 |
| 社会游戏：地雷爆炸 | 参与“听到地雷就跳一跳、听到爆炸就向前走”的游戏形式。老师反馈其参与情况较好，规则执行仍需要少量引导。 | 老师讲解并带领执行游戏规则。 |
| 问题解决：别人挡住去路 | 看视频时能够描述“他挡住路了”，先提出找老师告状，并在追问下说出“老师，他挡住路了”；未自行想出第二种直接请对方让路的办法。角色扮演中，老师挡路时，他会说“你挡住我的路了，快让一让”；当对方表示不让开后，他继续要求让路，没有转而向陈老师求助。 | 老师提醒第二种办法是直接告诉挡路者让开；角色扮演中，在对方持续不让路时，老师提示可转而向陈老师告状。 |
| 问题解决：高处物品 | 能够说出搬椅子、找老师帮忙拿两种办法。角色扮演中先踩椅子尝试；需要老师帮助时会提出请求。老师故意表现为没有拿到时，他会提醒“陈老师，你好好拿”。 | 老师通过视频描述、提出办法和角色扮演三个步骤练习；在角色扮演中设置需要继续调整办法的情境。 |
| 问题解决：物品掉进柜子缝里 | 能够说出移开柜子、伸手去拿；被问到柜子移不开怎么办时，又说出找陈老师帮忙。角色扮演中会尝试移动柜子、伸手拿，物品太靠里拿不到时会请求“陈老师，你帮我拿行吗”。 | 老师追问原有办法无法实施时还能怎么办，并在角色扮演中回应其求助。 |
| 向同伴提出要求 | 共练习向同伴要物品 5 次。前 2 次在老师示范下伸手并说“可以给我……吗”或“我要……”；后 3 次老师未提醒，他能够主动伸手等待同伴把物品交给自己，没有直接上手拿。老师反馈，与前一天相比，直接抢拿的情况减少。 | 前 2 次老师示范伸手等待和请求用语；后 3 次撤除提示，让可乐自行提出要求。 |
| 邀请同伴参加游戏 | 在地雷爆炸、捉迷藏和抢椅子等活动中，老师说明要玩的游戏并指定邀请对象后，可乐会走到同伴旁边发出邀请。 | 老师告知游戏内容、邀请对象，并要求可乐去邀请同伴。 |
| 邀请同伴玩玩具 | 玩兔子农场时，听到邀请指定同伴一起玩的要求后，可乐走到同伴旁边，但没有说话，直接放下玩具并和同伴一起玩。 | 老师提醒需要先向同伴说出邀请，让对方知道要一起做什么。 |
| 集体指令：搬椅子和站红线 | 当天第一次出现“请小朋友们搬椅子”的集体指令时，可乐抱着超市商品板，询问是否需要当老板，没有去搬椅子；经提醒后完成。游戏结束再次听到搬椅子指令时，能够较快搬到指定位置；后续听到站红线的集体指令时，也能够较快站过去。老师结合前一天的情况指出，两天均是当天第一次集体指令需要提醒，后续执行较快。 | 第一次未执行时，老师提示观察已去搬椅子的同伴，并明确说明“现在是搬椅子的时间”；后续指令未提及针对可乐的额外提醒。 |

老师表示，节后会继续练习超市老板角色、不同形式的地雷爆炸游戏、挡路情境中的多种解决办法、向同伴提出要求、邀请同伴玩玩具，以及不同内容的集体指令。这些是后续教学计划，并非今天已达到的表现。
