# 可乐画像维护

`wiki/可乐画像.md` 是当前概览；`tracking/log/` 保存具体事件。画像中的机构目标、当前表现和待确认信息分别记录，不用目标推断表现。

## 更新流程

1. 读取画像和本次相关的日志或原始资料。若本次同时写日志，先遵循[家庭日志技能](../family-intervention-log/SKILL.md)或[机构日志技能](../institution-intervention-log/SKILL.md)的收集与确认流程，日志落盘后再同步画像。
2. 判断新信息属于家长／老师转述、日志中的观察事实、资料观点、分析推测，还是待确认内容。记录信息日期与来源；日志证据链接到具体文件。关键表述有歧义且会改变画像结论时先提问；家长选择后续补充的细节留在“待家长补充或确认”。
3. 只修订受影响的条目。背景信息与干预目标可按家长明确提供的内容更新；单次观察先保留场景、行为及支持程度，有足够跨次证据时再概括趋势。新旧表现不一致时写明场景差异。评估转述按原意标注，不推定正式诊断。
4. 更新页首核对日期及“更新记录”，写明本次变更和依据。年龄以出生日期和核对日期计算；保留可追溯的旧日志，不用旧年龄表述替代出生日期。
5. 交付前核对日期、来源链接、目标与表现的区分，以及未提供的次数、原因、支持方式是否被误写成事实。向家长简要说明实际改动和仍待补充的关键细节。

仅有新日志而未改变当前概览时，画像无需改写；完成核对即可。修改日志本身仍遵循对应日志技能。
